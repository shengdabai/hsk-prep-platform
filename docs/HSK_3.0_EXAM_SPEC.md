## 一、等级体系：三等九级

来源：[教育部发布公告](http://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202103/t20210329_523304.html)

**总体信息**

| 项目 | 数值 |
|------|------|
| 总题数 | 40 题 |
| 考试科目 | 听力 + 阅读（共两部分）|

| 词汇量要求（旧版） | 150 词 |

**听力部分（20题，约15分钟）**

| 分部 | 题数 | 题型描述 | 作答形式 | 是否需要音频 | 是否需要图片 |
|------|------|---------|---------|------------|------------|
| 第一部分 | 5题 | 听一个**短语/词**，试卷提供1张图片，判断图文是否对应 | 判断对/错（✓/✗）| ✅ 是 | ✅ 是 |
| 第二部分 | 5题 | 听一个**句子**，试卷提供3张图片，选出对应图片 | 单选（从3图选1）| ✅ 是 | ✅ 是 |
| 第三部分 | 5题 | 听一段**简短对话**，试卷提供若干图片，选出对应图片 | 单选（从图片选1）| ✅ 是 | ✅ 是 |
| 第四部分 | 5题 | 听一人说一句话，另一人提问并说3个选项，选出答案 | 单选（从A/B/C选1）| ✅ 是 | ❌ 否 |

**阅读部分（20题，15分钟）**

| 分部 | 题数 | 题型描述 | 作答形式 | 是否需要音频 | 是否需要图片 |
|------|------|---------|---------|------------|------------|
| 第一部分 | 5题 | 图片+词语，判断图文是否对应 | 判断对/错（✓/✗）| ❌ 否 | ✅ 是 |
| 第二部分 | 5题 | 读一个句子，从若干图片中选出对应图片 | 单选（选图）| ❌ 否 | ✅ 是 |
| 第三部分 | 5题 | 问句与回答配对（A-F六个选项，含1个干扰项）| 配对/连线 | ❌ 否 | ❌ 否 |
| 第四部分 | 5题 | 句子中有空白，选词填空 | 单选（填空）| ❌ 否 | ❌ 否 |

来源：[HSK1级样卷 chinesetest.cn](https://www.chinesetest.cn/userfiles/file/HSK1.pdf)、[以色列孔子学院样卷 H10902](https://confucius-huji.co.il/wp-content/uploads/2017/03/H10902.pdf)

## 五、与旧版 HSK 2.0 的关键差异（HSK 3.0 变化要点）

来源：[StudyCLI 新版HSK详解](https://studycli.org/hsk/the-new-hsk/)、[DigMandarin 对比](https://www.digmandarin.com/new-hsk.html)、[文心书院 HSK 3.0 vs 旧版](https://visionchinese.com/learningresources/hsk/hsk-3-0-vs-old-6-levels-comparison-1774005018198/)、[唯壹汉语 HSK3.0 通知](https://www.jiaoyubao.cn/news/n273310.html)

### 5.1 等级数扩充

旧版6级 → 新版9级（三等九级），新增高等7-9级，专门覆盖学术/专业领域高水平学习者。

### 5.2 词汇量大幅提升

| 级别 | 旧版 HSK 2.0 词汇量 | 新版 HSK 3.0 词汇量（GF0025-2021 对应）| 增幅 |
|------|------------------|--------------------------------------|------|
| 1 级 | 150 词 | 500 词 | +233% |
| 2 级 | 300 词 | 1,000 词 | +233% |
| 3 级 | 600 词 | 2,245 词 | +274% |
| 4 级 | 1,200 词 | 3,245 词 | +170% |
| 5 级 | 2,500 词 | 4,316 词 | +73% |
| 6 级 | 5,000 词 | 5,456 词 | +9% |
| 最高 | 5,000 词（6级止）| 11,092 词（9级合计）| +122% |

### 5.3 口语考试：从"可选独立"变为"强制绑定"

- **旧版**：HSKK 口语与 HSK 笔试完全独立，考生可自由选择是否参加
- **新版**：HSK 3-6 级考试**强制绑定**口语考试，报名笔试必须同步报名对应口语
- HSK 1-2 级和 HSK 7-9 级的口语安排：**未查到权威确认数据**（7-9级口语已融入笔试试卷，1-2级是否绑定待确认）

### 5.4 新增翻译题型（仅高等 7-9 级）

旧版无翻译题型。新版 7-9 级新增笔译和口译，考查考生将英/西/日/韩等7种外语译为中文的能力。

### 5.5 新增汉字大纲

新版 HSK 3.0 大纲新增了独立的**汉字大纲**，对各级别需要手写的汉字数量有明确规定（见第一节表格）。旧版无独立汉字书写要求体系。

### 5.6 考试内容导向变化

- 新版加大对**当代中国社会发展、科技进步、生态文明建设**等领域语料的考查
- 新版强化中华优秀传统文化内容
- 新版融入 AI 命题、AI 监考、AI 评分技术

### 5.7 实施时间线

| 时间 | 事件 |
|------|------|
| 2021-03-31 | GF0025-2021《国际中文教育中文水平等级标准》发布 |
| 2021-07-01 | GF0025-2021 正式实施 |
| 2022-11-26 | HSK 7-9 级全球首考 |
| 2025-11-14~16 | 2025世界中文大会，HSK 3.0 大纲及样题正式发布 |
| 2025-11-18 | HSK 3.0 大纲正式发布实施 |
| 2026-01-31 | HSK 3.0 全球试行启动 |
| 2026-07 | HSK 3.0 全面正式实施，旧版 HSK 2.0（6级制）停考 |

- L1-L3 级图片应清晰直白；L4+ 级图片可以包含更复杂的场景

```

```

### 9.3 题型（question_type）字段设计

建议在 `question_type` 表中包含：

```sql
id               -- 自增主键
slug             -- 题型代码（如 L_WORD_IMG_TF）
name_zh          -- 中文名称

levels           -- JSONB 数组，出现的级别
answer_format    -- 作答形式代码
requires_image   -- boolean
requires_audio   -- boolean
audio_play_count -- 音频播放次数（1 或 2）
notes            -- 备注说明
```
